# C++ Questions & Practice

Welcome to my C++ learning repository!

This repository is dedicated to practising and strengthening my C++ programming fundamentals through various coding questions, exercises, and problem-solving challenges.

## About This Repository

This is a purely educational repository created as part of my journey to learn and improve my C++ programming skills.

It contains:
- Fundamental C++ programming exercises.
- LeetCode-style questions and problem-solving challenges.
- Concept-based programming questions.
- Practical exercises to improve logical thinking and coding skills.

## Topics Covered So Far

The repository currently includes questions based on:

- **Strings** – String manipulation and related problems.
- **Structures (`struct`)** – Creating and working with user-defined data types.
- **Enumerations (`enum` and `enum class`)** – Working with named constants and strongly typed enumerations.
- **Unions (`union`)** – Understanding shared memory and memory-efficient data representation.

More topics will be added as I progress through C++.

## Repository Structure

The questions are organised into folders based on their respective concepts to keep everything organised and easy to navigate.
